# 持仓状态一致性检查工具使用说明

## 功能说明
此工具包包含两个版本：
1. **手动检查版本** - 用于临时检查和手动确认修复
2. **自动服务版本** - 后台自动检查并修复持仓状态不一致问题

## 版本选择

### 手动检查版本 (position_consistency_check.go)
- 交互式操作，需要用户确认
- 适合首次使用或特殊情况处理
- 提供详细的检查报告

### 自动服务版本 (auto_service/)
- 完全自动化后台运行
- 每小时自动检查一次
- 只处理安全的自动修复场景
- 记录详细的执行日志

## 使用方法

### 手动检查版本
```bash
# 1. 配置数据库连接（修改position_consistency_check.go中的连接参数）
# 2. 编译并运行
cd scripts/position_fix
go build position_consistency_check.go
./position_consistency_check
```

### 自动服务版本
```bash
# 1. 配置数据库连接（修改auto_service/auto_position_fix_service.go中的连接参数）
# 2. 启动服务
cd scripts/position_fix/auto_service
start_auto_service.bat
```

## 自动化工作机制

### 检查逻辑
1. **定时执行**：每小时自动运行一次
2. **安全过滤**：只处理开仓超过24小时的记录
3. **自动修复**：符合条件的记录自动更新为CLOSED状态
4. **日志记录**：详细记录每次检查和修复的结果

### 安全机制
- 只自动处理历史记录（>24小时）
- 近期交易需要人工确认
- 所有操作在数据库事务中执行
- 完整的执行日志便于追溯

## 日志管理
自动服务会在 `logs/` 目录下生成日志文件：
- 按日期分割日志文件
- 记录每次检查的详细结果
- 包含修复统计和异常情况

## 注意事项
1. 首次使用建议先运行手动版本确认配置正确
2. 确保数据库连接参数配置正确
3. 建议在系统启动时自动运行自动服务
4. 定期检查日志文件确保服务正常运行
