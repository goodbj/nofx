## 配置步骤

### 1. 登录系统
- 访问: http://localhost:3300
- 使用注册的账号登录

### 2. 创建AI模型配置
1. 点击左侧导航栏的"AI模型"或"Traders"页面
2. 点击"添加AI模型"或"配置AI模型"
3. 选择模型类型（推荐使用GUARDIAN-AI）
4. 配置API密钥或使用默认设置
5. 保存配置

### 3. 创建交易所配置
1. 在"交易所"页面点击"添加交易所"
2. 选择交易所类型（推荐使用Binance Futures）
3. 配置API密钥（测试阶段可使用模拟盘）
4. 保存配置

### 4. 创建交易员
1. 在"交易员"页面点击"创建交易员"
2. 填写交易员名称
3. 选择已配置的AI模型
4. 选择已配置的交易所
5. 设置扫描间隔（建议5-10分钟）
6. 配置其他参数（杠杆、币种等）
7. 点击"创建"

### 5. 启动交易员
1. 在交易员列表中找到刚创建的交易员
2. 点击"启动"按钮
3. 等待系统开始生成决策记录

### 6. 查看决策记录
1. 返回仪表板页面
2. 选择已启动的交易员
3. "最近决策"区域将开始显示AI决策记录
4. 决策记录每30秒自动刷新

## 验证配置成功

配置完成后，您应该能看到：

- "最近决策"区域显示决策记录
- 决策记录包含cycle_number、时间戳、决策内容等信息

## 常见问题

**Q: 为什么"最近决策"显示为空？**
A: 需要先创建并启动交易员，系统才会开始生成决策记录。

**Q: 决策记录多久更新一次？**
A: 前端每30秒自动刷新，实际更新频率取决于交易员的扫描间隔设置。

**Q: 如何查看历史决策记录？**
A: 在"最近决策"区域可以查看最新的决策，也可以导出完整的历史记录。

**Q: 决策记录中的cycle_number是什么？**
A: 这是决策周期编号，每次AI决策都会递增，用于追踪决策顺序。

## 技术说明

- **决策生成机制**：交易员按照设定的时间间隔自动调用AI进行市场分析和决策
- **数据存储**：决策记录存储在SQLite数据库的`decision_records`表中
- **前端刷新**：使用SWR库实现30秒间隔的数据刷新
- **实时性**：决策记录生成后会立即在前端显示
