# 端口变更通知

## 更改说明

为了适应本地开发环境中的端口占用情况，我们将开发环境的默认端口进行了更改：

- **前端端口**: 从 3000 改为 3300
- **后端端口**: 从 8080 改为 8888

## 影响范围

这些更改仅影响本地开发环境，不影响 Docker 部署配置。

## 服务地址

- **前端界面**: http://localhost:3300
- **后端 API**: http://localhost:8888
- **API 文档**: http://localhost:8888/swagger/index.html

## 使用方法

运行以下命令启动开发环境：

```cmd
local_dev_setup.bat
```

或者手动启动：

```bash
# 启动后端
go run main.go

# 在另一个终端启动前端
cd web
npm run dev
```

## 注意事项

1. 确保端口 8888（后端）和 3300（前端）未被其他应用占用
2. 配置已自动更新到 `.env` 文件
3. Vite 配置已更新代理设置
