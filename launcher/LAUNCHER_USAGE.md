# NOFX 启动器使用说明

## 概述
NOFX 启动器是一个图形界面工具，用于便捷地启动和管理 NOFX AI 交易系统的前后端服务。它提供了直观的按钮操作和实时日志显示功能。

## 功能特性

### 主要功能
- **启动后端服务**: 启动开发版后端服务（端口 8888）
- **启动前端服务**: 启动开发版前端服务（端口 3300）
- **启动全部服务**: 同时启动前后端服务
- **停止所有服务**: 停止所有正在运行的服务
- **实时日志显示**: 显示服务运行时的详细日志信息
- **状态监控**: 实时显示服务运行状态

### 端口配置
- **后端端口**: 8888 (http://localhost:8888)
- **前端端口**: 3300 (http://localhost:3300)

## 使用方法

### 1. 直接运行 Python 脚本
```bash
python launcher_complete.py
```

### 2. 构建可执行文件
运行构建脚本：
```bash
build_launcher.bat
```

构建完成后，会在 `dist` 目录下生成 `NOFX_Launcher.exe` 文件，双击即可运行。

### 3. 使用图形界面
- **启动后端服务**: 点击按钮启动后端服务
- **启动前端服务**: 点击按钮启动前端服务
- **启动全部服务**: 同时启动前后端服务
- **停止所有服务**: 停止所有运行中的服务
- **查看日志**: 实时查看服务运行日志

## 系统要求
- **Docker Desktop**: 必须安装并运行 Docker Desktop
- **Python 3.6+**: 用于运行 Python 脚本或构建可执行文件
- **Windows 10/11**: 推荐运行环境

## 注意事项

1. **Docker 服务**: 确保 Docker Desktop 正在运行
2. **端口占用**: 确保端口 8888 和 3300 未被其他程序占用
3. **权限问题**: 可能需要管理员权限运行
4. **防火墙**: 确保防火墙允许相关端口的访问

## 常见问题

### Docker 未安装
如果出现 "未找到 docker 命令" 错误，请安装 Docker Desktop 并确保服务正在运行。

### 端口被占用
如果服务无法启动，请检查端口 8888 和 3300 是否被其他程序占用。

### 权限不足
如果遇到权限问题，请尝试以管理员身份运行启动器。

## 构建可执行文件

要构建 .exe 文件，您需要：

1. 安装 Python 3.6+
2. 运行 `build_launcher.bat` 脚本
3. 等待构建完成
4. 在 `dist` 目录中找到生成的 `NOFX_Launcher.exe` 文件

构建过程会自动安装所需的 PyInstaller 工具。

## 开发信息

- **主脚本**: `launcher_complete.py`
- **构建脚本**: `build_launcher.bat`
- **界面库**: Tkinter (Python 内置)
- **构建工具**: PyInstaller

## 许可证

此启动器仅供 NOFX 项目开发和测试使用。
