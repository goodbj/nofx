# Guardian 浏览器自动化功能

## 概述

Guardian 是 NoFx 系统中的一个特殊 AI 模型类型，它不使用传统的 API 调用来获取 AI 响应，而是通过浏览器自动化技术将提示词发送到浏览器中的 AI 服务（如 DeepSeek Web、ChatGPT Web 等），然后获取 AI 的响应。

## 功能特点

- **浏览器自动化**：使用 chromedp 或其他浏览器自动化工具
- **无需 API 密钥**：绕过传统 API 调用，使用浏览器界面
- **灵活的 AI 服务支持**：可连接到任何 Web 界面的 AI 服务
- **集成到现有流程**：无缝集成到 NoFx 的 AI 决策流程中

## 使用方法

### 1. 在前端配置

在交易员配置页面中，将 AI 模型类型设置为 `guardian`：

- Provider: `guardian`
- Model: `guardian-browser-automation`

### 2. 后端行为

当 AI 模型设置为 `guardian` 时：

1. 系统会创建 `GuardianClient` 实例
2. 调用 `CallWithMessages` 时，会触发浏览器自动化流程
3. 提示词会被发送到浏览器中的 AI 服务
4. AI 的响应会被捕获并返回给系统

### 3. 浏览器自动化流程

目前，浏览器自动化功能仍在开发中。完整实现将包括以下步骤：

1. 启动浏览器实例
2. 导航到指定的 AI 服务页面
3. 将系统提示词和用户提示词输入到页面
4. 触发 AI 处理
5. 等待并获取 AI 响应
6. 将响应返回给 NoFx 系统

## 配置选项

在未来的实现中，Guardian 可能支持以下配置：

- `GUARDIAN_AI_URL`：AI 服务的 URL
- `GUARDIAN_BROWSER_HEADLESS`：是否使用无头模式
- `GUARDIAN_TIMEOUT`：浏览器操作超时时间

## 注意事项

- Guardian 功能依赖于浏览器自动化，需要系统能够启动和控制浏览器
- 确保系统上安装了兼容的浏览器（如 Chrome/Chromium）
- 浏览器自动化可能比 API 调用慢一些，但可以访问那些不提供 API 的 AI 服务
- 需要考虑反爬虫措施和速率限制

## 开发状态

当前状态：浏览器自动化功能正在开发中，目前返回模拟响应。

要启用完整的浏览器自动化功能，需要：
1. 添加 chromedp 依赖
2. 实现具体的浏览器操作逻辑
3. 处理错误和重试机制
4. 添加配置选项

## 故障排除

如果 Guardian 模型无法正常工作：

1. 检查 AI 模型配置是否正确设置为 `guardian`
2. 查看日志中是否有相关错误信息
3. 确认系统环境是否满足浏览器自动化的要求
