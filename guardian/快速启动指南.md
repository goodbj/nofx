# Guardian Docker 快速启动指南

本指南将帮助您快速启动Guardian监测程序的Docker环境。

## 前期准备

### 1. 配置Docker镜像加速器（重要）

如果在中国大陆地区，强烈建议配置Docker镜像加速器：

1. 打开Docker Desktop
2. 点击Settings → Docker Engine
3. 替换配置为以下内容：

```json
{
 "registry-mirrors": [
   "https://hub-mirror.c.163.com",
   "https://mirror.baidubce.com",
   "https://docker.mirrors.ustc.edu.cn",
   "https://registry.docker-cn.com"
 ]
}
```

4. 点击 Apply & Restart

### 2. 确保环境要求

- Docker Desktop 已安装并运行
- Docker Compose 已启用
- Go 环境已安装（用于Web控制面板）

## 启动方式

### 方式一：使用Web控制面板（推荐）

1. 启动Web控制面板：
   ```bash
   cd e:\AI\nofx_Dev\guardian
   go run web_controller.go
   ```

2. 访问 `http://localhost:8085`

3. 通过网页界面选择环境并点击启动按钮

### 方式二：使用批处理脚本

1. 运行：
   ```cmd
   start_guardian_docker.bat
   ```

2. 选择对应的环境（生产或开发）

### 方式三：使用Docker Compose命令

#### 启动开发环境（含Guardian）：
```bash
# 首次构建（如果遇到网络问题，使用--build跳过缓存）
docker-compose -f docker-compose.dev.with-guardian.yml up -d --build

# 后续启动（不重新构建）
docker-compose -f docker-compose.dev.with-guardian.yml up -d
```

#### 启动生产环境（含Guardian）：
```bash
# 首次构建
docker-compose -f docker-compose.with-guardian.yml up -d --build

# 后续启动
docker-compose -f docker-compose.with-guardian.yml up -d
```

## 如果遇到构建错误

如果遇到TLS连接错误或网络问题，请尝试以下解决方案：

### 1. 清理Docker构建缓存
```bash
docker builder prune -a
```

### 2. 单独构建Guardian镜像
```bash
docker build -f docker/Dockerfile.guardian -t nofx-guardian .
```

### 3. 使用国内镜像源构建
我们的Dockerfiles已配置了国内镜像源，但如果您仍遇到问题，可以：

1. 检查Docker Engine配置是否包含镜像加速器
2. 尝试使用VPN或代理（如适用）
3. 在网络状况较好的时段重试

## 验证服务状态

启动后验证服务是否正常运行：

```bash
# 检查开发环境服务状态
docker-compose -f docker-compose.dev.with-guardian.yml ps

# 检查生产环境服务状态
docker-compose -f docker-compose.with-guardian.yml ps
```

## 查看日志

查看Guardian服务日志：

```bash
# 开发环境
docker logs -f nofx-guardian-dev

# 生产环境
docker logs -f nofx-guardian
```

## 停止服务

```bash
# 停止开发环境
docker-compose -f docker-compose.dev.with-guardian.yml down

# 停止生产环境
docker-compose -f docker-compose.with-guardian.yml down
```

## 常见问题

1. **TLS错误**: 确保已配置Docker镜像加速器
2. **端口占用**: 确保8888、3300等端口未被占用
3. **内存不足**: 确保Docker分配了足够的内存（建议至少4GB）
4. **权限问题**: 确保以管理员身份运行命令提示符

## 环境变量配置

确保 `.env` 文件中配置了必要的环境变量：

```bash
# Guardian 配置
GUARDIAN_API_KEY=your_api_key_here
GUARDIAN_AUTH_TOKEN=your_auth_token_here
GUARDIAN_AI_PROVIDER=deepseek
GUARDIAN_AI_ENDPOINT=https://chat.deepseek.com
GUARDIAN_LISTEN_INTERVAL=5000
```
