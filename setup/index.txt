NOFX Docker 部署工具集
========================

此目录包含用于快速部署和管理NOFX Docker环境的脚本。

可用脚本:
-----------

1. install-dev.bat
   - 功能: 部署开发版NOFX环境
   - 端口: 前端3300, 后端8888
   - 特点: 支持热更新，适合开发调试

2. install-prod.bat
   - 功能: 部署稳定版NOFX环境
   - 注意: 需要预先准备好docker-compose.prod.yml

3. cleanup.bat
   - 功能: 清理所有NOFX相关的Docker容器和资源
   - 注意: 保留数据库文件(data.db)

4. verify-deployment.bat
   - 功能: 验证当前部署状态
   - 输出: 显示运行中的容器和服务状态

5. quick-start.bat
   - 功能: 交互式快速部署向导
   - 特点: 提供菜单选择不同部署选项

6. system-status.bat
   - 功能: 检查双系统运行状态
   - 特点: 显示稳定版和开发版的容器状态

7. docker-compose.stable.yml
   - 稳定版部署配置文件

8. docker-compose.dev.watch.yml
   - 开发版部署配置文件

9. deploy-stable.bat
   - 稳定版一键部署脚本

10. deploy-dev.bat
   - 开发版一键部署脚本

11. install-files.bat
   - 部署文件安装脚本，用于将部署文件复制到稳定版和开发版目录

12. README.md
   - 详细部署文档，包含故障排除指南

使用说明:
-----------
- 确保在运行脚本前已正确配置 .env 文件
- 确保 Docker 服务正在运行
- 数据库文件保存在 E:\AI\nofx_Dev\data\data.db
- 所有脚本应在 setup 目录中运行

部署流程:
-----------
1. 首次部署: 运行 install-dev.bat 或 install-prod.bat
2. 验证部署: 运行 verify-deployment.bat
3. 问题排查: 参考 README.md 的故障排除章节
4. 环境重置: 运行 cleanup.bat 后重新部署
