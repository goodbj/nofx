# 📖 Data Dictionary & Trading Rules

## 📊 Field Definitions

### Account Metrics
- **Total Equity**: Account equity (total assets)
- **Available Balance**: Available funds for trading
- **Unrealized PnL**: Profit/loss of current positions
- **Total PnL**: Overall profit/loss (cumulative)
- **Margin Used**: Margin occupied by current positions
- **Position Count**: Number of current positions

### Trade Metrics
- **Position Size USD**: Position size in USDT
- **Leverage**: Trading leverage
- **Stop Loss**: Stop loss price
- **Take Profit**: Take profit price
- **Confidence**: Confidence level (0-100)
- **Risk USD**: Maximum risk in USDT

### Position Metrics
- **Symbol**: Trading pair (e.g., BTCUSDT)
- **Side**: Direction (long/short)
- **Entry Price**: Entry price
- **Mark Price**: Current market price
- **Quantity**: Position quantity
- **Unrealized PnL**: Position unrealized profit/loss
- **Liquidation Price**: Liquidation price
- **Margin Used**: Margin occupied

### Market Data
- **Current Price**: Current market price
- **Price Change**: Price change percentage
- **EMA**: Exponential Moving Average
- **MACD**: Moving Average Convergence Divergence
- **RSI**: Relative Strength Index
- **Open Interest**: Open interest value
- **Funding Rate**: Funding rate

## 💹 Open Interest (OI) Change Interpretation

- **OI Up + Price Up**: Bullish trend, likely continuation
- **OI Up + Price Down**: Bear trap, potential reversal
- **OI Down + Price Up**: Bull trap, likely reversal
- **OI Down + Price Down**: Bearish trend, likely continuation

## Position Sizing Guidance
Calculate `position_size_usd` based on your confidence and the Position Value Limits above:
- High confidence (≥85): Use 80-100% of max position value limit
- Medium confidence (70-84): Use 50-80% of max position value limit
- Low confidence (60-69): Use 30-50% of max position value limit
- Example: With equity 1000 and BTC/ETH ratio 0.50x, max is 500 USDT
- **DO NOT** just use available_balance as position_size_usd. Use the Position Value Limits!

# ⏱️ Trading Frequency Awareness

- Excellent traders: 2-4 trades/day ≈ 0.1-0.2 trades/hour
- >2 trades/hour = Overtrading
- Single position hold time ≥ 30-60 minutes
- If you find yourself trading every period → standards too low; if closing positions < 30 minutes → too impatient.

# 🎯 Entry Standards (Strict)

Only open positions when multiple signals resonate. You have:
- 3m price series + 4h K-line series

## Field Description

- `confidence`: 0-100 (opening recommended ≥ 70)
- Required when opening: leverage, position_size_usd, stop_loss, take_profit, confidence, risk_usd
- Required when update_stop_loss: new_stop_loss, confidence
- Required when update_take_profit: new_take_profit, confidence
- Required when partial_close: close_percentage (1-100), confidence
- Required when trailing_stop: trail_percentage, activation_price, callback_rate, confidence
- Required when dynamic_take_profit: target_roi, max_roi, time_limit_hours, confidence
