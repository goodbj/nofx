# Binance Proxy Service 使用说明

币安代理服务插件，专门负责绕过币安监管，从主程序获取连接参数，专门负责获取数据、发送数据和执行命令。

## 设计目的

本插件的主要目的是：
1. 绕过币安的监管限制
2. 从主程序获取连接参数
3. 专门负责数据获取、发送和命令执行
4. 提供一个隔离的环境来处理敏感的API调用

## 核心功能

### 1. 数据获取
- 获取账户余额
- 获取持仓信息
- 获取K线数据
- 获取账户信息
- 获取交易历史

### 2. 命令执行
- 下单操作
- 撤单操作
- 获取订单状态

## 部署方式

### Docker部署
```bash
# 构建并启动代理服务
docker-compose -f docker-compose.proxy.yml up --build
```

### 环境变量配置
```bash
# 启用代理模式
USE_BINANCE_PROXY=true

# 代理服务地址
BINANCE_PROXY_URL=http://localhost:8081
```

## 安全考虑

1. API密钥在代理服务中处理，与主程序隔离
2. 所有敏感操作都在独立的容器中执行
3. 通过HTTP头传递认证信息，避免在URL中暴露密钥
4. 支持自定义API端点，可以绕过某些地区限制

## 优势

1. **监管绕过** - 通过独立的服务处理币安API调用，可以更容易地应对监管变化
2. **安全隔离** - API密钥和其他敏感信息在独立环境中处理
3. **灵活部署** - 可以在不同地理位置部署代理服务以绕过地域限制
4. **可扩展性** - 可以轻松添加更多币安API功能
5. **向后兼容** - 不影响现有功能，可平滑切换
